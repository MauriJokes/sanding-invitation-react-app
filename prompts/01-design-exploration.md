# Design Exploration

Activate the `wedding-ui-design` skill.

Read `docs/DESIGN_SYSTEM.md` and `design-assets/moodboard/NOTES.md`, then inspect all supplied visual references and assets. Infer theme and decoration from `design-assets/moodboard/theme/` only; use `design-assets/moodboard/uiux-sample/` only to infer the user journey and overall flow.

Do not build the full website yet.

Produce:
- A concise visual direction.
- Typography recommendations.
- A proposed colour palette grounded in the supplied references.
- Layout and interaction principles.
- A small set of representative page/section concepts.
- Responsive and accessibility considerations.

Do not invent final brand assets, wedding copy or venue information. Identify missing inputs. Wait for owner approval before implementing the full design system.
